# Домашняя работа: Weather MCP 2.0

В архиве находится стартовый проект и инструкции для общей работы по первым четырём занятиям курса.

## Что внутри

- `ЗАДАНИЕ.md` — полное условие и критерии оценивания;
- `weather-mcp/` — стартовый MCP-сервер без решения домашней задачи;
- `Agent.md` — описание процесса для оркестратора;
- `agents/` — промпты ролей для поэтапной работы;
- `.codex/config.toml` — пример настройки основной модели и субагентов;
- `prompts/` — сюда нужно положить главный промпт домашней работы;
- `artifacts/` — сюда складываются результаты работы агентов.

## Как начать

1. Распакуйте архив в отдельную папку.
2. Откройте всю распакованную папку в Codex, а не только каталог `weather-mcp`.
3. Проверьте, что установлены Node.js 20 или новее и npm.
4. В терминале выполните:

```powershell
cd weather-mcp
npm install
npm run ci
```

До внесения изменений исходный проект должен собраться, а все исходные тесты должны пройти.

## Как запустить работу с AI

Сначала прочитайте `ЗАДАНИЕ.md`. Затем отправьте Codex следующий запрос, заменив фамилию:

```text
Обработай домашнюю задачу Weather MCP 2.0 по процессу из Agent.md.

Идентификатор задачи: HW-WEATHER-<фамилия>.
Условие находится в файле ЗАДАНИЕ.md, исходный проект — в папке weather-mcp.

Сначала выполни только анализ и планирование. Создай требуемые артефакты в artifacts/HW-WEATHER-<фамилия>/ и главный промпт в prompts/homework-weather-mcp.md. Используй отдельные роли Analyst, Planner и Critic. Не изменяй исходный код, пока я не просмотрю и не одобрю implementation-plan-v2.md.
```

После проверки плана можно разрешить реализацию:

```text
План одобрен. Продолжи задачу HW-WEATHER-<фамилия> по Agent.md. Запусти роли Builder, Tester и Reviewer, реализуй новый MCP-инструмент, выполни npm run ci и заполни verification.md и final-review.md. Не скрывай ошибки и не отмечай проверки успешными, если они не запускались.
```

## Что сдавать

Точный список находится в `ЗАДАНИЕ.md`. Перед отправкой обязательно проверьте наличие:

- изменённого проекта `weather-mcp`;
- `prompts/homework-weather-mcp.md`;
- каталога `artifacts/HW-WEATHER-<фамилия>/` со всеми артефактами;
- результатов `npm run ci`;
- краткой личной рефлексии.

Не добавляйте в сдаваемый архив `node_modules`, секреты, токены и файлы `.env`.
