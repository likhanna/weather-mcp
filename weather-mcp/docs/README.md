# Weather MCP

Локальный MCP-сервер на Node.js и TypeScript. Он предоставляет прогноз погоды и помогает оценивать погодные риски для наружных работ на основе Open-Meteo. Для Open-Meteo API-ключ не требуется.

## MCP-инструменты

- `get_weather` — текущая погода и прогноз по дням для города (от 1 до 7 дней).
- `assess_weather_risk` — оценка риска для запланированных работ по почасовому прогнозу.
- `find_safe_weather_window` — поиск наиболее подходящих почасовых окон работ в заданном интервале.
- `compare_weather_windows` — сравнение двух временных окон для одинакового города и типа работ.

Временные аргументы для инструментов оценки и поиска задаются по московскому времени в формате `YYYY-MM-DDTHH:mm`.

## Установка и запуск

Требуется Node.js 20+ и npm. Из каталога проекта:

```powershell
npm install
npm run build
npm start
```

Для запуска из TypeScript при разработке используйте `npm run dev`. Сервер работает по STDIO: подключите его к MCP-клиенту или запустите через Inspector (`npm run inspect`). В Inspector также можно запустить собранный сервер командой `npx @modelcontextprotocol/inspector node dist/index.js`.

## Тесты и проверки

```powershell
npm test
npm run ci
```

`npm run ci` собирает проект и запускает тесты.

## Пример

Вызов `get_weather` через MCP-клиент:

```json
{
  "city": "Dubai, United Arab Emirates",
  "days": 3
}
```

Ответ включает найденные город и страну, текущие погодные условия и дневные минимумы и максимумы температуры.
